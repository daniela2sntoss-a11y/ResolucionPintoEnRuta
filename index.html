01 · PLANTEAMIENTO

Objetivo del proyecto

El objetivo fue crear una aplicación web que funcionase como guía turística y local de Pinto. La primera petición se centraba en mostrar patrimonio, barrios, gastronomía y ocio mediante tarjetas, navegación por secciones y un tema claro/oscuro.

A partir de esa base, fui ampliando la aplicación según los requisitos nuevos y corrigiendo los problemas detectados: se añadieron el menú lateral, filtros, el planificador climático, el Pasaporte Pinteño, imágenes y un comparador histórico. Las fases siguientes documentan esas entregas en el mismo orden en que se solicitaron.

PRIMERA ENTREGA · GUÍA BASE

Creación de la guía turística de Pinto

Versión inicial

La primera solicitud definió las cuatro áreas principales y los requisitos visuales básicos. El resultado fue una web sencilla de varias secciones con HTML, CSS y JavaScript separados.

Prompt 1 · Solicitud inicial
Actúa como un Diseñador UI/UX y Desarrollador Frontend experto.

Quiero que me diseñes la estructura y el código base (HTML, CSS y JavaScript) para una aplicación web multipantalla o de pestañas que funcione como una guía turística y local completa sobre mi pueblo: Pinto (Madrid).

El objetivo es practicar maquetación avanzada, diseño con cards, transiciones fluidas y un sistema de cambio entre modo claro y modo oscuro.

La aplicación de Pinto debe incluir las siguientes secciones clave en formato de fichas o pantallas:
1. Puntos de Interés Turístico e Histórico: Torre de Éboli, el diseño del municipio como centro geográfico de la Península Ibérica, Parque Municipal.
2. Zonas y Barrios: Pinto Centro, El Egido o La Indiana.
3. Gastronomía: restaurantes, bares de tapas recomendados y platos típicos de la zona.
4. Deportes y Ocio: instalaciones municipales, polideportivos como el Amelia del Castillo y zonas verdes.

Requisitos técnicos y de diseño:
- Modo Claro / Oscuro: botón accesible para alternar dinámicamente el tema mediante variables CSS.
- Maquetación y Transiciones: CSS Grid/Flexbox, cards con zoom o sombra al pasar el ratón y transiciones suaves.
- Diseño Adaptativo (Responsive): móvil y ordenador.

Entrégame el código estructurado (HTML, CSS y JavaScript) listo para probar.
Solución proporcionada

Se entregó una primera carpeta con index.html, styles.css, app.js y README.md. Incluía las secciones informativas, tarjetas, navegación entre apartados y alternancia de tema claro/oscuro.

SEGUNDA ENTREGA · AMPLIACIÓN

Arquitectura avanzada, menú lateral y gamificación

Nueva estructura

Se pidió elevar el nivel de la aplicación y convertirla en una experiencia interactiva. La interfaz incorporó filtros, controles avanzados y un sistema de progreso para las visitas.

Prompt 2 · Requisitos avanzados
Actúa como un Diseñador UI/UX Senior y Desarrollador Frontend experto.

Quiero que me diseñes la estructura completa y el código base (HTML, CSS y JavaScript moderno) para una aplicación web/móvil interactiva que funcione como una guía turística avanzada sobre Pinto (Madrid).

El objetivo es demostrar maquetación avanzada, componentes de interfaz complejos, estados de interacción y diseño centrado en el usuario.

1. Arquitectura de navegación y estética:
- Design Tokens: variables CSS para colores, tipografías, sombras y espaciados.
- Navigation Drawer: menú lateral deslizable para cambiar de sección y filtrar vistas, por ejemplo, Modo Paseo Tranquilo o zonas de sombra.
- Estados hover, active, focus y disabled en botones, tarjetas y elementos interactivos.

2. Componentes de UI:
- Cards interactivas para Torre de Éboli, Parque Municipal Juan Carlos I, Iglesia de Santo Domingo de Silos, etc.
- Carrusel horizontal de fotografías o comparador visual «Máquina del Tiempo» entre Pinto histórico y actual.

3. Características innovadoras:
- Date & Time Picker con termómetro de calor y avisos contextuales para horas de mucho calor o aforos altos, con alternativas de interior.
- Pasaporte Pinteño: check-in en tarjetas o al seleccionar una fecha, sellos dorados y curiosidades desbloqueables.
- Modo claro/oscuro dinámico y accesible.

Entregable: estructura HTML, CSS responsive y JavaScript para el menú lateral, selector de fechas y cambio de tema.
Solución proporcionada

Se rediseñó la aplicación con design tokens, navegación lateral deslizable, filtros de paseo tranquilo y sombra, carrusel, comparador histórico y Pasaporte Pinteño. Los sellos y curiosidades se desbloqueaban mediante interacciones y el progreso se conservaba en el navegador.

SÉPTIMA ENTREGA · ÚLTIMO FALLO DETECTADO

Corrección de la imagen de la Torre de Éboli en el carrusel

Última corrección

Después de corregir las imágenes de la Máquina del Tiempo, se detectó otro fallo independiente: la tarjeta de la Torre de Éboli en «Un paseo en imágenes» no cargaba ninguna fotografía.

Prompt 7 · Imagen que no carga en el carrusel
La imagen de «Un paseo en imágenes», Torre de Éboli, no carga ninguna imagen.
Solución proporcionada

Se incorporó una cadena de fuentes de respaldo para la imagen de la Torre. Si falla la primera URL, JavaScript prueba las alternativas y, finalmente, puede utilizar el recurso histórico local. Así se evita que la tarjeta se quede sin imagen si una fuente remota deja de responder.

Fragmento de la corrección aplicada en JavaScript
document.querySelectorAll('img[data-fallbacks]').forEach((image) => {
  const candidates = (image.dataset.fallbacks || '').split('|').filter(Boolean);
  let candidateIndex = 0;

  image.addEventListener('error', () => {
    if (candidateIndex < candidates.length) {
      image.src = candidates[candidateIndex++];
      return;
    }
    image.classList.add('image-load-failed');
  });
});

Mostrar prompt consolidado utilizado
Actúa como un Diseñador UI/UX Senior y Desarrollador Frontend experto. Desarrolla una aplicación web completa, responsive e interactiva que funcione como una guía turística avanzada de Pinto (Madrid), utilizando HTML5, CSS3 y JavaScript moderno, preferiblemente sin frameworks para que el código sea fácil de estudiar y modificar.

OBJETIVO Y CONTENIDO
Crea una experiencia visual de turismo local, con diseño editorial cuidado y navegación clara. Incluye fichas de patrimonio e historia (Torre de Éboli, Iglesia de Santo Domingo de Silos y referencia al centro geográfico de la Península Ibérica), zonas y barrios (Pinto Centro, El Egido y La Indiana), gastronomía local (Ombligos de Pinto, pastelerías y Chocolates El Indio) y deporte y ocio (Estadio Amelia del Castillo, Polideportivo El Egido y parques municipales).

DISEÑO Y ARQUITECTURA
- Define design tokens mediante variables CSS para paleta, tipografías, tamaños, espaciados, radios, sombras y transiciones.
- Incluye modo claro y oscuro, persistiendo la preferencia del usuario.
- Implementa un Navigation Drawer lateral con navegación entre secciones y filtros de paseo tranquilo y zonas de sombra/interior.
- Diseña cards interactivas con imagen, categoría, descripción, indicadores y estados hover, active, focus-visible y disabled.
- Crea cuatro accesos de categoría con ilustraciones SVG estilo flat design: historia, barrios, gastronomía y deporte.
- Usa CSS Grid y Flexbox, jerarquía tipográfica y un diseño responsive para móvil, tablet y escritorio.

PLANIFICADOR CLIMÁTICO
- Incluye selectores de fecha y hora.
- Para junio, julio, agosto y septiembre, entre las 13:00 y las 19:00, muestra una alerta de calor severo/extremo y recomienda evitar la exposición al sol, cambiar a actividades interiores y pasear en horas más frescas.
- Propón alternativas de interior relacionadas con Pinto.
- Deja claro que se trata de una simulación orientativa si no se conecta una fuente meteorológica real; no presentes temperaturas estimadas como datos en directo.

GALERÍA Y MÁQUINA DEL TIEMPO
- Añade un carrusel horizontal de fotografías de Pinto con botones anterior/siguiente, puntos de navegación, indicador de posición, soporte táctil y teclado, y transiciones fluidas.
- La Máquina del Tiempo debe comparar únicamente la Casa Consistorial (Ayuntamiento) y la Torre de Éboli.
- Utiliza las dos fotografías históricas proporcionadas por la usuaria como imágenes del pasado, sin sustituirlas por otras, recortarlas ni convertirlas. Añade una fotografía contemporánea identificada para cada edificio.
- Implementa un comparador deslizante tipo cortina para revelar pasado y presente. Indica las fechas y créditos disponibles; no inventes que una fotografía es actual si no se conoce su fecha.

GAMIFICACIÓN
- Añade el Pasaporte Pinteño con sellos que se desbloquean al visitar tarjetas o completar acciones.
- Muestra curiosidades asociadas a los lugares y guarda el progreso mediante localStorage.
- Incluye estados visuales de sello bloqueado y desbloqueado y una barra de progreso.

CALIDAD Y ENTREGA
- Mantén el código organizado, comentado y funcional.
- Evita controles decorativos que no hagan nada.
- Comprueba las rutas de imágenes y añade recursos de respaldo si una imagen externa no carga.
- Respeta accesibilidad básica: etiquetas, aria-label, foco visible, navegación por teclado y contraste.
- Entrega el HTML, CSS y JavaScript completos, con instrucciones para ejecutar y publicar en GitHub Pages.
